# Darokel Studio | Fine Art Photography

A minimalist, elegant, and timeless photography portfolio website for **Darokel Studio**.

## 📸 Features
- **Minimalist Aesthetic:** Clean white-space and high-end typography to let the photography shine.
- **Dynamic Portfolio:** Filterable masonry-style gallery (Weddings, Portraits, Events, Commercial).
- **Immersive Lightbox:** View high-resolution images in a distraction-free fullscreen mode.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
- **Contact & Booking:** Streamlined inquiry form and direct contact details.

## 🛠️ Technology Stack
- **HTML5:** Semantic structure with SEO optimization.
- **CSS3:** Custom Vanilla CSS for maximum performance and fluid animations.
- **JavaScript:** Native logic for gallery filtering and lightbox functionality.

## 🚀 Deployment
This site is optimized for **Vercel**. 

### How to Deploy:
1. **GitHub Import:** Push this folder to a GitHub repository and import it into Vercel.
2. **Drag-and-Drop:** Drag this folder into the Vercel dashboard.
3. **Vercel CLI:** Run `vercel` in the terminal to deploy instantly.
